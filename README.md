# Tides Today Tides and Weather

Build reusable Tides Today tide and weather widgets for WordPress and place them with a shortcode, a classic sidebar widget, or a Gutenberg block.

## Development

Run the JavaScript syntax checks:

```bash
npm run lint:js
```

Run the PHP and JavaScript tests:

```bash
npm run test
```

The WordPress.org plugin readme remains in [readme.txt](./readme.txt).
